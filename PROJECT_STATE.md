## 2. Архитектура (как это работает)

1. **GUI (PyQt6)** → Пользователь перетаскивает **файлы или целые папки** (Drag & Drop), выбирает модель из списка и задаёт промпт → 
2. **ExtractionWorker (QThread)** → Запускает фоновый процесс (GUI не зависает, работает кнопка Stop) → 
3. **Парсер (pypdf/python-docx)** → Извлекает сырой текст из файлов → 
4. **LLM Extractor (Ollama)** → Отправляет текст в выбранную модель с системным промптом → 
5. **JSON Parser (json-repair)** → Гарантированно парсит ответ LLM в словарь Python → 
6. **Excel Exporter (Pandas)** → Собирает все словари в один DataFrame, выравнивает колонки и сохраняет в `.xlsx` через `QFileDialog`.

*Безопасность и приватность: Все данные обрабатываются локально через Ollama. Никаких внешних API (OpenAI и т.д.).*

## 4. Журнал фиксов и решений (Fix Log)

*   **Fix 1 (Ollama API):** Библиотека `ollama` возвращает объекты Pydantic вместо словарей при вызове `.list()`. **Решение:** Обработка через `getattr()` и проверка `isinstance(dict)`.
*   **Fix 2 (JSON Hallucinations):** Локальные LLM иногда оборачивают JSON в markdown-теги. **Решение:** Использование `json-repair`.
*   **Fix 3 (Pandas Auto-width):** `pandas` падал с ошибкой `object of type 'float' has no len()` при пустых ячейках (`NaN`). **Решение:** Использование `lambda x: len(str(x))` для принудительного приведения к строке.
*   **Fix 4 (Thread Safety):** При обработке списка файлов один битый файл мог уронить весь поток. **Решение:** Внедрена обработка исключений (`try/except`) внутри цикла `ExtractionWorker`.
*   **Fix 5 (PyQt6 Drag & Drop):** Переопределение методов `dropEvent` напрямую в экземпляре `QListWidget` игнорировалось движком C++ Qt. **Решение:** Создан кастомный класс `DropListWidget(QListWidget)` с переопределенными событиями.
*   **Fix 6 (QComboBox Styling):** Выпадающий список моделей отображался белым текстом на белом фоне. **Решение:** Добавлены QSS-стили для `QComboBox QAbstractItemView`.
*   **Fix 7 (QMessageBox Styling):** Системные всплывающие окна наследовали светлый текст на светлом фоне. **Решение:** Явно заданы стили `QMessageBox` в `styles.py`.
*   **Fix 8 (Folder Drag & Drop):** Пользователь мог перетаскивать только отдельные файлы. **Решение:** В `DropListWidget` добавлена проверка `os.path.isdir()`. Если перетаскивается папка, используется `os.walk` для рекурсивного поиска всех поддерживаемых файлов (PDF, DOCX, TXT).
